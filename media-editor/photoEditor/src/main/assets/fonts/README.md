# Fonts for texts

Unchanged font files from the Google Fonts repository, https://github.com/google/fonts
(only Caveat and Playfair Display were renamed from `Caveat[wght].ttf` and
`PlayfairDisplay[wght].ttf`; they are variable fonts, the editor uses their default weight).

| Font | File | Licence |
|---|---|---|
| Bebas Neue | BebasNeue-Regular.ttf | SIL Open Font License 1.1, OFL-bebasneue.txt |
| Anton | Anton-Regular.ttf | SIL Open Font License 1.1, OFL-anton.txt |
| Pacifico | Pacifico-Regular.ttf | SIL Open Font License 1.1, OFL-pacifico.txt |
| Caveat | Caveat.ttf | SIL Open Font License 1.1, OFL-caveat.txt |
| Permanent Marker | PermanentMarker-Regular.ttf | Apache License 2.0, LICENSE-permanentmarker.txt |
| Playfair Display | PlayfairDisplay.ttf | SIL Open Font License 1.1 (Reserved Font Name "Playfair Display"), OFL-playfairdisplay.txt |
| Lobster | Lobster-Regular.ttf | SIL Open Font License 1.1 (Reserved Font Name "Lobster"), OFL-lobster.txt |

The fonts are bundled with the app and never downloaded.
